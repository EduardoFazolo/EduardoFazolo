### Tools I built, and use every day

**[iframer](https://iframer.sh)**
Agentic browser. Captchas, bot detection, complex logins, plus an API reverse engineering toolkit so agents can automate the things that have no API.

**[canvaflow](https://github.com/EduardoFazolo/canvaflow)**
Infinite canvas where I watch every agent and project at once.

**[lupesource](https://github.com/EduardoFazolo/lupesource)**
Source control for agents. Shares prompt history between them and solves the git worktree problem, so I can run several branches at the same time.

**[brain](https://github.com/EduardoFazolo/brain)**
Small local memory for agents. Skills, documents, the things worth keeping.

**[vaemon](https://github.com/EduardoFazolo/vaemon)**
Cron daemon so my agents can wake themselves up later and carry on.

They are built to connect. Together they turn my Mac into a multi agent setup I actually trust.
